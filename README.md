# Классификация музыкальных треков по географии (ML-проект)

Этот проект даёт ML-пайплайн, который предсказывает регион автоматически - для рекомендаций и анализа каталога.

## Цель 
- решает проблему ручного поиска региона по музыке.

## Ключевые функции
- Загрузка трека и определение географического региона
- Рекомендация музыки по географическому региону
- Анализ каталога
- Качество модели засчет метрик
